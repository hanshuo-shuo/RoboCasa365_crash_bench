## Verification that passed

On a Quest login node, this command successfully created the official
`robocasa/PickPlaceCounterToCabinet` pretrain environment, called `reset()`,
sampled one action, called `step()`, and closed the environment:

```bash
/projects/p33100/siosio/envs/robocasa-foundation/bin/python -c '
import gymnasium as gym
import robocasa
env = gym.make("robocasa/PickPlaceCounterToCabinet", split="pretrain", seed=0)
env.reset()
env.step(env.action_space.sample())
env.close()
'
```

`gymnasium` emitted its passive observation-space warning. It did not prevent
creation, reset, or stepping and is recorded as an upstream wrapper warning,
not a passing claim about all render modes.

## Known limitation: LeRobot dataset utilities

`pip check` reports exactly one unsatisfied top-level dependency:

```text
robocasa 1.0.1 requires lerobot, which is not installed.
```

RoboCasa 1.0.1 pins `lerobot==0.3.3`. Its dependency resolution requires
`rerun-sdk>=0.21.0,<0.23.0`; both Quest's configured index and direct PyPI only
offered `rerun-sdk>=0.23.4` on 2026-08-31. Installing an incompatible newer
package would make the environment appear complete while losing reproducibility,
so it was deliberately not done.

This does **not** affect RoboCasa task construction, MuJoCo simulation,
controllers, kitchen assets, or the passed smoke test. Source inspection found
LeRobot imports only in `robocasa/utils/lerobot_utils.py` and the dataset
conversion/info scripts. Therefore LeRobot-format dataset conversion is the
only unavailable feature. Do not work around this by modifying package metadata
or adding an unpinned package. Revisit only if the foundation explicitly needs
dataset conversion and a compatible upstream release/source pin is identified.

## Optional-component warnings

Imports can mention missing `robosuite_models`, Mink-based whole-body IK, or
MimicGen. They are optional components for robots/controllers/data-generation
paths not used by the verified default PandaOmron RoboCasa task. Do not install
them unless a selected foundation task or controller actually requires them.
